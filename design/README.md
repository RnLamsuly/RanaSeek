# Logo 素材目录

把你选好的 logo 图片放在这个目录里，建议文件名：`logo.png`。

## 图片规格建议

| 项目 | 建议 |
| --- | --- |
| 格式 | PNG（透明背景最佳） |
| 尺寸 | 正方形，≥ 512×512（1024×1024 更好，启动图标要用） |
| 构图 | 主体居中、四周留一点安全边距（约 8%） |
| 背景 | 透明，或纯深色（App 是黑底 #0F0F0F） |
| 颜色 | 主体在深色底上要清晰可辨（浅色/品牌蓝 #507BF2 系最佳） |

## 姐姐会拿它做这些事

1. 首页中央的大 logo（约 92dp）
2. 侧边栏底部用户头像（圆形裁剪）
3. 桌面启动图标（自适应图标：深色背景 + 居中主体）
4. 对话页里自己的头像（小圆）

> 如果图片是白底、不是透明背景，跟姐姐说一声，姐姐可以用脚本帮你把白底去掉（效果取决于图片边缘复杂度，简单图形效果很好）。
