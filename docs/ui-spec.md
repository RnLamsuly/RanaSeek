# RanaSeek UI 设计规格（对齐 DeepSeek 移动端风格）

> 来源：主人提供的 DeepSeek Android 2.8.0（`com.deepseek.chat`）实机截图 + APK 资源表取色。
> 只参考「设计风格与视觉规范」，代码与官方图片/图标素材不复制、不复用。
> 采样设备：1264×2736 px @560dpi（density 3.5，dp = px / 3.5）。

## 一、技术栈

- Kotlin + Jetpack Compose（官方 2.8.0 判断为原生 Kotlin + Compose 实现，与本项目一致）
- AGP 9.5.1 内置 Kotlin，`compileSdk 37` / `targetSdk 37` / `minSdk 24`
- 状态管理：ViewModel + StateFlow；持久化：DataStore / Room；网络：OkHttp + SSE 解析

## 三、字体与字号

官方使用系统字体（荣耀设备为 HarmonyOS Sans），本项目跟随系统字体即可。

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 首页欢迎语「你好，我能帮什么忙吗？」 | 30sp | Bold |
| 对话正文 / Markdown | 16sp，行高 26sp | Normal |
| 输入框文字与占位符 | 16sp | Normal |

## 四、布局与尺寸

### 首页（截图 1）

- 顶部栏：高约 48dp；左侧「≡」菜单按钮（点击打开侧边栏）；右侧「耳机/朗读」与「⊕ 新对话」两个图标按钮
- 中部：鲸鱼 logo（约 96dp，品牌蓝）+ 欢迎语，整体垂直居中偏上
- 底部输入区（截图 2 显示展开态）：
  - 卡片外边距 16dp，圆角 28dp，背景 `surface`
  - 内部上：多行输入框（placeholder「发消息或按住说话」），最小高度约 52dp，无边框
  - 内部下：左侧「深度思考」胶囊（底 `#283142`、文字品牌蓝、图标为两个菱形交叠）+「智能搜索」胶囊（地球图标），高约 32dp，圆角全圆
  - 右侧：加号圆形按钮（44dp，描边圆）+ 语音圆形按钮（44dp）
  - 发送状态：加号按钮变为「×」关闭按钮；面板上方出现附件缩略图行 + 「拍照 / 相册 / 文件」三个圆角方形卡片（截图 2）
- 底部：系统导航栏区域保持 `bg`

### 侧边栏（截图 3）

- 宽度约 320dp（屏幕 360dp 的 ~89%）
- 顶部搜索框：高 40dp、圆角 20dp、背景 `#292929`、左侧放大镜图标、placeholder「搜索对话内容...」
- 「置顶」分组：右侧有排序图标（`≡` 带点）
- 分组标题 13sp 灰色，行间距紧凑
- 列表项：高约 48dp，17sp 白字，单行省略
- 「今天」分组同理
- 底部用户行：头像 36dp 圆形 + 用户名 17sp + 右侧「⋯」更多按钮
- 抽屉打开时主界面被深色遮罩覆盖

### 选择对话（截图 4）

- 顶栏：左侧标题「选择对话」+ 右侧圆形「×」关闭按钮（40dp）
- 列表行：左侧 24dp 圆形勾选框（未选中为 1.5dp 灰色描边）+ 文字
- 底部操作栏：左侧「置顶」按钮（星形图标 + 文字）、右侧「删除」按钮（垃圾桶 + 文字），文字灰白色 16sp
- 顶栏/操作栏背景略深于列表

### 设置页（截图 5）

- 顶栏：左侧 40dp 圆形返回按钮（背景 `#2A2A2A`），居中标题「设置」18sp
- 分组：`账户`（账号管理、数据管理）、`应用`（语言、外观、字体大小、个性化）、`语音`（朗读音色）、`关于`（检查更新 + 版本号、服务协议…）
- 每个分组：13sp 灰色标题（左侧 16dp 缩进）+ 圆角 20dp 卡片（背景 `#292929`），卡片内每行高 56dp，左右内边距 20dp
- 行内：左侧 24dp 线性图标（灰色），标题 16sp 白字，右侧值 15sp 灰字（如「中文（简体中文）」「深色」「2.8.0(297)」）+ 右侧 16dp 灰色 `>` 箭头
- 分组之间留白约 24dp

## 五、图标策略

- 采用 Material Symbols Outlined（线性风格）最接近官方观感：`menu`、`add_circle`、`record_voice_over`、`search`、`language`、`dark_mode`、`text_fields`、`auto_awesome`、`person`、`database`、`volume_up`、`info`、`chevron_right`、`check_circle`、`push_pin`、`delete`、`close`、`photo_camera`、`photo_library`、`attach_file`、`mic`、`arrow_upward`
- 「深度思考」图标为两个交叠菱形，可用 `all_inclusive` / 自绘 path 近似
- 鲸鱼 logo：自绘矢量（圆胖鲸鱼 + 眼睛），不使用官方图片资源；颜色 `brand`

## 六、动效与交互

- 侧边栏：从左侧滑入 + 主界面缩放/压暗（约 250ms，FastOutSlowIn）
- 输入面板展开：高度过渡 + 附件行淡入
- 流式回答：文字逐字出现，末尾闪烁光标；「深度思考」过程默认折叠，点击展开，展开时显示思考耗时
- 联网搜索：回答上方显示「已搜索 N 个网页」可折叠卡片，正文中引用角标可点击跳转
- 长按消息：复制/引用/删除/重新生成（Material 3 弹层或底部 ActionSheet）

## 七、与官方差异

- 不使用官方 logo 图片、图标素材、字体文件；姐姐自绘 + Material Symbols + 主人提供的头像图
- 不实现登录/账号体系：用「设置页填 API Key」替代登录
- 首版不包含：多设备同步、语音朗读音色选择（如后续需要再补）

## 八、新增设置项（v0.2，非官方功能）

### 1. 主题模式
`外观 → 主题模式`：跟随系统 / 浅色 / 深色。深色为默认。
配色通过 `RsPalette` + `CompositionLocal` 下发，所有界面跟随切换；状态栏图标颜色同步。
浅色值：`bg #FFFFFF`、`surface #F2F2F4`、`surfaceElevated #ECECEF`、`bgSettings #F7F7F8`、`brand #426EFE`。

### 2. 全局人设（system prompt）
`设置 → 全局人设`：多行文本，作为 system 提示词放在每次对话开头；存 DataStore。

### 3. 聊天背景
`外观 → 聊天背景`：系统 Photo Picker 选图 → 全屏裁剪页（双指缩放、单指拖动）→ 导出 1080 宽 JPEG 存 app 私有目录。
- 虚化程度：0~25（`Modifier.blur`，API 31+；低版本自动降级为不虚化）
- **选好背景后自动切换到浅色主题**（若当前为深色）
- 支持移除背景

### 4. 消息框风格
`外观 → 消息框风格`：
- 纯色：`surface` 实色气泡
- 亚克力：`textPrimary 16%` 半透明 + 12% 描边（对话页渲染时生效）

### 5. 头像与图标
- 桌面图标：主人提供图片的正方形裁剪版，自适应图标（背景色取图片边缘主色 `#30548A`，前景按 65% 安全区缩放）
- 首页/侧边栏/对话页头像：同一图片的圆形裁剪（头肩特写，`avatar.png`）
